# Support

DragonForge Test Lab is an active development project and public portfolio repository candidate, not a commercial support service.

For ordinary bugs, documentation problems, or feature ideas, use the repository's GitHub issue templates when issues are publicly available. Include the affected commit/version, operating system, relevant configuration with secrets removed, reproduction steps, and sanitized logs where useful.

Do not post credentials, tokens, private keys, proprietary repositories, personal data, or sensitive security evidence in public issues. Vulnerabilities belong in the private process described in [SECURITY.md](SECURITY.md).

Unsolicited code contributions are not currently accepted; see [CONTRIBUTING.md](CONTRIBUTING.md).
